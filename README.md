My personal Ao3 site skin. I recommend you change the skins icons and primary skin icons, to your preferences. 
Also, please add the mobile skin and link it with the main skin for maximum effect. The bow and the  dashboard 
does clash and will make it hard to click on the link.

Create the Mobile Skin:
1. Go to Dashboard → Skins → My Site Skins → Create Site Skin.
2. Paste your mobile-specific CSS (e.g., @media queries or overrides).
3. Scroll to Advanced Options.
4. Under What It Does, select Parent Only.
5. Under Choose @media, select only screen and (max-width: 42em) (this targets mobile/narrow screens).
Submit the skin.


Link It to Your Main Skin:
1. Go to your Main Site Skin (the one you use normally).
2. Scroll to Advanced Options.
3. Click Add Parent Skin and select the mobile skin you just created from the dropdown.
4. Submit/Update the main skin.
